# WorkMap API

Бэкенд сервиса WorkMap — каталога мест для продуктивной работы в городе: кофеен, коворкингов, библиотек и антикафе. Помогает студентам и удалённым сотрудникам найти место с Wi-Fi, розетками и подходящим уровнем шума.
